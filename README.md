# 本地加密保险箱 (Secure Vault)

一个完全在**本地**运行的图片 / 视频加密工具。文件用密码加密后变成 `.svenc` 密文，
**密码错误时在密码学上无法解开、无法查看内容**（不是"隐藏"，是真加密）。

> 🔽 **免安装版**：到 [Releases](../../releases) 页面下载 `加密保险箱.exe`，双击即用，无需安装 Python。

## 怎么运行

**推荐**：双击 **加密保险箱.exe** —— 免安装、无需 Python，任何 Windows 10/11 电脑都能直接用。

也可以：双击 `启动加密保险箱.bat`（需要电脑装有 Python 和加密库）。

命令行方式：

```
python secure_vault.py             # 打开图形界面
python secure_vault.py --selftest  # 自检（验证加解密功能是否正常）
```

## 功能

### 🔒 加密
1. 切到「加密」页，点 **添加文件** 或 **添加文件夹**（会递归找出文件夹里所有图片/视频）
2. 输入密码并确认（有实时强度提示，建议 8 位以上混合字符）
3. 点 **开始加密**，每个文件旁生成一个 `.svenc` 密文文件

加密选项：
- **隐藏原文件名**：密文用随机名（如 `SV-3FA2B1C9.svenc`），外人看不出里面是什么（原文件名加密存放在文件内部，解密时自动恢复）
- **加密成功后安全删除原文件**：先覆写随机数据再删除（建议先手动解密一次确认无误后再勾选）

### 🔓 解密 / 预览
- **解密到原位置**：在密文所在目录恢复出原始文件（自动还原原文件名，重名自动加 (1)）
- **👁 解密并预览**：解密到**系统临时目录**并用默认程序打开（看图 / 播放视频），看完点
  「🧹 彻底清理临时文件」一键覆写删除；忘记点也没关系，关闭软件时会自动清理。
  这样查看内容不在原位置留下解密副本。
- 密码错误 → 立即提示「密码错误」并停止，**不会有任何内容被解出**

### 其他便利
- 批量处理、大视频流式读写（不占内存）、进度条 + 当前文件名、中途取消
- 文件列表支持**右键菜单**（打开所在文件夹 / 移除 / 清空）
- 密码框内按 **Enter** 直接开始
- 处理日志带颜色：成功绿 / 失败红 / 警告黄
- Windows 高分屏（高 DPI）下界面清晰不模糊

## 安全原理

| 环节 | 方案 |
|------|------|
| 加密算法 | AES-256-GCM（认证加密，行业标准） |
| 密码派生 | PBKDF2-HMAC-SHA256，600,000 次迭代 + 随机盐 |
| 随机数 | 每个文件独立随机 nonce（96 位） |
| 完整性 | GCM 认证标签，文件被篡改会拒绝解密 |
| 原文件名 | 加密后存放在密文内部，不看密码拿不到 |
| 防暴力猜密码 | 每次错误密码后附加延迟；PBKDF2 本身 60 万次迭代 |

- 全程离线，密码不上传、不落盘、无任何后门。
- 密文开头存有由密码派生的校验值：密码不对时**第一块数据**就校验失败，直接报「密码错误」。

## ⚠️ 重要提醒

- **密码忘了 = 文件永远打不开**。AES-256 没有办法绕过或找回，请务必记牢密码。
- 单个文件上限约 64 GB（GCM 算法限制）。
- `.svenc` 文件可以随意复制、移动、上传网盘，不影响解密。
- 想给别人发文件：把 `.svenc` 文件发过去，口头/另行告知密码即可。
- 「安全删除」对 SSD 无法做到绝对不可恢复（固态盘物理特性决定，任何软件都一样），
  如需绝对安全请对整盘加密（如 BitLocker）。
